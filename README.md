# 🌐 Repositório de Projetos Web

Este repositório contém quatro projetos distintos, cada um abordando diferentes temas e melhorias no desenvolvimento web. A seguir, estão os detalhes de cada projeto:

## 🌟 Projetos Incluídos

### 1. **Biblioteca Virtual - Versão Básica**
Este projeto é uma implementação básica de uma biblioteca virtual. Ele contém as funcionalidades essenciais para catalogar livros e permitir a consulta por título e autor.

- **Tecnologias utilizadas**: HTML, CSS, JavaScript
- **Funcionalidades**:  
  - Exibir livros cadastrados com título e autor.
  - Interface simples e funcional.

### 2. **Biblioteca Virtual - Versão Melhorada**
Este é o código melhorado da biblioteca virtual. A versão aprimorada inclui novas funcionalidades e melhorias na interface, como:
- Atualizações

- **Tecnologias utilizadas**: HTML, CSS
- **Novidades(Será implementado no futuro)**:  
  - Pesquisa por gênero, ano e autor.
  - Interface de usuário aprimorada com CSS moderno.
  - Funcionalidades adicionais para tornar a biblioteca mais interativa e eficiente.

### 3. **Site de Flores para Casamento - Versão Básica**
Este é um site simples que exibe diferentes tipos de flores específicas para casamentos. O site mostra as flores populares com suas imagens e descrições básicas, ideal para quem busca inspiração para casamento.

- **Tecnologias utilizadas**: HTML, CSS
- **Funcionalidades**:  
  - Exibição de flores com nome, imagem e descrição.
  - Layout clean e direto ao ponto, sem interatividade avançada.

### 4. **Site de Flores para Casamento - Versão Futura**
A versão melhorada do site de flores para casamento inclui um design mais atraente, com maior interatividade. Agora, o site possui filtros para buscar flores por tipo, cor e preço, além de uma interface mais sofisticada.

- **Tecnologias utilizadas**: HTML, CSS, JavaScript
- **Novidades**:
- Filtro para Daltonismo
  - Filtros interativos para buscar flores por cor, tipo e preço.
  - Animações e transições para uma navegação mais fluída.
  - Layout responsivo para uma experiência otimizada em dispositivos móveis.
